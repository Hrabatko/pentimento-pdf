# 003 – Práce se stránkami: ruční test

Specifikace: [`specs/003-stranky.md`](../../specs/003-stranky.md)

## Příprava

1. Ve složce `<složka projektu>`: `npm.cmd run testdata`, pak `npm.cmd run dev`; v Chrome **http://127.0.0.1:5173**.
2. **Pracujte s kopiemi:** testovací soubory z `tests\data\` zkopírujte do nějaké pracovní složky (např. `D:\pokus\`) — aplikace do nich bude ukládat.
3. Heslo k `heslo.pdf`: `testovaci-heslo`.
