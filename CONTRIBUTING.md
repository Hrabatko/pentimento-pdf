# Reporting problems / Hlášení chyb

## English

Thank you for helping to improve Pentimento PDF!

**Bug reports and suggestions are welcome** in this repository's **Issues**. Please include:

1. what you did (steps),
2. what you expected and what happened instead (an exact error message helps),
3. the program version (**⋯ → About**) and your Windows version.

**Never attach confidential documents.** If a problem only shows up with a particular PDF, describe it, or create a test PDF without personal data.

**Pull requests are not accepted.** Pentimento PDF is a personal project developed by one person; please report the problem or idea as an issue instead and it will be considered. Thank you for understanding.

The program is free software under the GPL-3.0-or-later license: you may study, modify and share it under its terms (see [LICENSE](LICENSE)).

## Česky

Děkujeme, že pomáháte Pentimento PDF zlepšovat!

**Hlášení chyb a návrhy jsou vítané** v sekci **Issues** tohoto úložiště. Uveďte prosím:

1. co jste dělali (postup),
2. co jste čekali a co se stalo místo toho (přesné znění chyby pomůže),
3. verzi programu (**⋯ → O programu**) a verzi Windows.

**Nikdy nepřikládejte důvěrné dokumenty.** Když se problém projeví jen u konkrétního PDF, popište ho, nebo vytvořte testovací PDF bez osobních údajů.

**Úpravy kódu (pull requesty) nepřijímáme.** Pentimento PDF je osobní projekt jednoho člověka; nahlaste prosím chybu nebo nápad jako issue a zvážíme ho. Děkujeme za pochopení.

Program je svobodný software pod licencí GPL-3.0-or-later: můžete ho zkoumat, upravovat a šířit podle jejích podmínek (viz [LICENSE](LICENSE)).
