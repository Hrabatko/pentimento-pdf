# Privacy policy / Zásady ochrany osobních údajů

## English

**Pentimento PDF does not collect, store, send or share any personal data.**

- The program has no accounts, no telemetry, no analytics and no advertising.
- It makes no network connections. Documents are opened, edited and saved only on your computer.
- Settings (theme, language) and saved signature images are stored only on your computer, in the program's own data folder. Uninstalling the program leaves them there so that a reinstall keeps them; you can delete the folder yourself.
- When you install or update the program through the Microsoft Store, the Store itself works under Microsoft's privacy statement; the program receives no data from it.

Questions: please open an issue in the project's GitHub repository (do not include personal data).

Publisher: Hrabatko. Last updated: 2026-11-17.

## Česky

**Pentimento PDF nesbírá, neukládá, neodesílá ani nesdílí žádné osobní údaje.**

- Program nemá účty, telemetrii, analytiku ani reklamu.
- Nenavazuje žádné síťové spojení. Dokumenty se otevírají, upravují a ukládají jen ve vašem počítači.
- Nastavení (vzhled, jazyk) a uložené obrázky podpisů jsou jen ve vašem počítači, ve vlastní složce s daty programu. Odinstalace je tam nechá, aby zůstaly pro novou instalaci; složku můžete smazat sami.
- Když program instalujete nebo aktualizujete přes Microsoft Store, Store se řídí prohlášením společnosti Microsoft o ochraně osobních údajů; program od něj žádná data nedostává.

Dotazy: založte prosím hlášení (issue) v úložišti projektu na GitHubu (bez osobních údajů).

Vydavatel: Hrabatko. Naposledy aktualizováno: 2026-11-17.
